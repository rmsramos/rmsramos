## Hi, I'm Rômulo Ramos
### Tech lead and full-stack developer in Macapá, Amapá, Brazil 🇧🇷

Ten-plus years building software for the public sector, for companies and for my own ideas. Today I lead development teams and ship web systems with Laravel, Filament and the TALL stack, running on Docker, with AI-assisted workflows and MCP tooling as part of the daily routine. I also create and maintain open-source Filament plugins, Activitylog among them.

Off the clock I am a musician and a Linux user, which is how the projects below started: when a device I own only ships Windows software, I reverse-engineer its protocol and build a native Linux app for it.

## Linux apps for hardware

### New: MultiFX Editor 🎸

**[MultiFX Editor](https://github.com/rmsramos/multifx-editor)** is an unofficial Linux editor for the **M-VAVE Tank G** guitar multi-effects pedal. The official app has no Linux version, so I decoded its MIDI SysEx protocol and built a desktop app that edits all 36 presets directly on the pedal. Not affiliated with M-VAVE.

### Teclume ⌨️

**[Teclume](https://github.com/rmsramos/teclume)** is an unofficial Linux configurator for the **Fortrek Cruiser** RGB keyboard. The vendor app only runs on Windows and macOS, so I reverse-engineered the USB protocol and built a native one.

[![Release](https://img.shields.io/github/v/release/rmsramos/teclume?style=flat-square&color=8b5cf6)](https://github.com/rmsramos/teclume/releases/latest)
